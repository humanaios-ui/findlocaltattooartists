# Find Local Tattoo Artists

Modern tattoo portfolio website for Phoenix, AZ & Fort Walton Beach, FL.

Built with **Astro** + **Tailwind CSS** + **Decap CMS**.

## Features
- Dark minimalist design with vibrant ink accents (deep blacks, reds, golds)
- Filterable portfolio gallery with lightbox zoom
- Healed vs fresh work categories
- "Poco Loco" bold & approachable energy
- Dual location SEO (Phoenix + FWB)
- Git-based CMS for non-technical updates
- Mobile-first, ultra-fast static site

## Quick Start
```bash
git clone https://github.com/humanaios-ui/findlocaltattooartists.git
cd findlocaltattooartists
npm install
npm run dev
```

## Deployment
GitHub Pages (free) or Cloudflare Pages.
